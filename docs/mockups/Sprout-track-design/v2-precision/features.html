Features

A spec sheet, not a brochure.

Everything below ships in every plan, including free self-hosted installs. No feature gates, no premium tier, no asterisks.

Logging

Two taps, pre-filled from last time

Sixteen entry types with big targets and sensible defaults. Amounts remember themselves; timers run for naps, nursing, and pumping. Built for one hand and no sleep.

  • Sleep, feeds, diapers, pumping, solids
  • Medicine, vitamins, baths, activities, notes
  • Milestones, measurements, photos, milk storage
Shared access

Every caretaker on the same timeline

Invite the other parent, grandparents, and the nanny with a link and a PIN. Each entry is attributed, so the handoff question is already answered. Unlimited caretakers and babies on every plan.

  • PIN login simple enough for grandparents
  • Multiple babies, one-tap switching
  • Live daily summary: awake, sleep, oz, diapers
Records

Vaccines with the documents attached

Dose numbers, provider contacts, notes, and the clinic’s PDF or a photo of the card, stored with the record. Growth measurements chart over time next to the daily log.

  • Vaccine history with attachments
  • Healthcare provider contact book
  • Weight, height, head circumference
Nursery mode

A crib-side terminal for the night shift

Always-on, dimmed, and glanceable across a dark room. One tap starts a sleep timer or logs a feed. Wake lock keeps the screen alive; hue and dim sliders keep it from lighting up the nursery.

  • Configurable activity tiles
  • Background hue, dim, and saturation controls
  • Fullscreen kiosk-style display
Analysis

Reports that answer real questions

How long did she sleep this week? When did the cluster feeding start? Calendar, full log, and heatmap views make the pattern visible before you feel it.

dailySummary bar: awake time, total sleep, intake
calendarMonth view with per-day activity
full logFilter and search across all history
heatmapTime-of-day patterns across weeks
exportTake a full copy of your data anytime
devicesAny browser: phone, tablet, laptop
Self-hosting

The homelab path is a first-class citizen

Same codebase as the hosted service. Clone, compose, done.

$ git clone https://github.com/Oak-and-Sprout/sprout-track
$ cd sprout-track
$ docker compose up -d
→ listening on :3000 — invite your caretakers
